# 0. 使用说明

[返回目录](../battle-system-mechanics.md)

如果你的目标是“先把能跑的模拟器写出来”，建议按下面顺序实现：

1. **行动条/回合系统**：SPD、AV、行动提前、行动延后、额外回合、终结技插队。
2. **基础伤害系统**：常规伤害乘区、暴击、防御、抗性、易伤、减伤。
3. **弱点击破系统**：削韧、击破伤害、击破异常、Broken 状态恢复。
4. **状态机**：Buff/Debuff/控制效果的附加、递减、移除、不可驱散。
5. **资源系统**：SP、Energy、战前/每波事件。
6. **特殊动作**：追加攻击、反击、召唤物、倒计时对象、终结技插队。
7. **目标选择**：单体/扩散/群攻/弹射/随机目标/仇恨修正/锁定。
8. **角色脚本层**：把每个角色的天赋/技能写成事件监听器。
