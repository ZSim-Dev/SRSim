# 22. 一句话总结

[返回目录](../battle-system-mechanics.md)

如果你按这份文档实现：**把“时间线、伤害、击破、状态、插队动作”做成硬规则，把“SP、Energy、Aggro、Super Break 细节”做成配置项**，你就能做出一个结构正确、后续也方便逐步逼近实机的《崩坏：星穹铁道》战斗模拟器。

补充：对较新的特殊体系，建议把**忆灵**视为独立实体，把 **Elation DMG** 视为独立伤害类别，把 **Aha Instant** 视为专用结算窗口，而不是强行塞进旧版 summon / follow-up / normal DMG 的语义里。
