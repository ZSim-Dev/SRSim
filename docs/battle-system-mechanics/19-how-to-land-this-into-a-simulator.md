# 19. 最终建议：如何从这份文档落地成“可运行模拟器”

[返回目录](../battle-system-mechanics.md)

### 第一阶段：做“引擎正确”

先确保以下 5 件事完全正确：

1. 时间线推进
2. 普通伤害乘区
3. 削韧/击破/恢复
4. 状态时序
5. 插队动作（Ultimate / Extra Turn / FUA）

### 第二阶段：做“配置可替换”

把以下内容全部塞进配置：

- Energy 的受击模板与特殊返能表
- SP 的跨波继承与上限改写规则
- 仇恨优先级脚本与特殊目标规则
- 忆灵的目标可选性 / 波次 AV 保留规则
- Elation / Aha 的 Punchline 与专属倍率规则
- Super Break 参数
- 同 AV tie-breaker

### 第三阶段：做“角色脚本层”

角色技能不要污染通用引擎。
角色应该只是订阅事件、生成动作、修改状态、注入乘区。
