# 21. 当前报告的结论强度总结

[返回目录](../battle-system-mechanics.md)

### 可以直接编码的部分

- SPD / AV / AG 体系
- 速度变化
- 行动提前 / 延后
- 100% 拉条
- Ultimate 插队
- Extra Turn
- 忆灵作为独立战斗实体的建模思路
- 普通伤害乘区
- DEF / RES / Vulnerability / Mitigation / Broken 乘区
- Toughness / Weakness Break / Broken 恢复
- 各元素击破基础伤害倍率
- Elation DMG 作为独立伤害类别
- Aha Instant 作为专用结算窗口
- 多段攻击模型
- 战前 / 每波开始事件
- Buff/Debuff/控制的通用对象模型

### 建议配置化后编码的部分

- SP 的跨波继承与上限改写顺序
- Energy 的受击模板表与特殊动作返能细则
- Aggro 的 Lock-On / Taunt 优先级脚本
- 忆灵的目标可选性与跨波 AV 继承
- Elation / Aha 体系的精确资源与专属倍率细节
- Super Break 精确倍率
- 同 AV 平手优先级

### 需要后续录像/实测补齐的部分

- 新版本特殊机制（Exo-Toughness、部分新召唤体系）
- 某些角色专属“无视规则”的文本优先级
- 特定 Boss 的脚本化选目标逻辑
